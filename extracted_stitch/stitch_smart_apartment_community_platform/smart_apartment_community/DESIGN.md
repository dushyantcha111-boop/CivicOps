## Brand & Style
The design system establishes a high-trust, operational hub tailored for high-density modern gated societies and enterprise facility teams in India. Its brand personality combines executive architectural precision with community warmth: authoritative, hyper-reliable, effortless, and protective. 

The aesthetic is Modern Enterprise Civic SaaS—merging Material 3 structural discipline with contemporary executive software polish. Deep architectural navies ground navigation and high-security states, while crisp slate surfaces prioritize legibility under varied lighting (from guardhouse tablets to outdoor mobile use by residents). Visual noise is eliminated to maintain clarity during high-urgency operations such as visitor gate clearances, security escalations, and multi-tier society governance.

## Colors
The palette balances structural enterprise authority with immediate operational feedback.

- **Primary (`#2563EB`)**: Royal Blue anchors primary actions, selected navigation states, verified links, and key interaction cues.
- **Secondary (`#0F172A` / `#1E293B`)**: Midnight Slate and Deep Navy serve as executive surfaces, dense headers, persistent sidebars, and critical system typography.
- **Tertiary & Semantic Success (`#10B981`)**: Emerald represents verified passes, paid dues, resolved maintenance tickets, and gate approvals.
- **Warning & Pending (`#F59E0B`)**: Warm Amber signals pending visitor approvals, scheduled amenities, overdue maintenance windows, and in-progress requests.
- **Critical & Emergency (`#EF4444`)**: Crimson Red is reserved strictly for SOS security alerts, fire safety, unauthorized gate intrusions, and hard payment failures.
- **Surface & Background**: Pure white (`#FFFFFF`) cards and structural containers layer cleanly atop an off-white slate foundation (`#F8FAFC`), bordered with subtle slate dividers (`#E2E8F0`).

## Typography
The system adopts a dual-typeface structure engineered for institutional scale:

- **Display & Headlines (`Plus Jakarta Sans`)**: Provides approachable geometry, modern refinement, and distinctive executive presence on high-level society analytics, onboarding banners, and committee dashboard metric summaries.
- **Body, UI, & Data Tables (`Inter`)**: Utilitarian, screen-optimized grotesque engineered for ultra-dense data sheets, flat maintenance registries, unit numbers (e.g., Tower 4 - Flat 1202), time logs, and transaction breakdowns.
- **Micro-Copy & Monospace Requirements**: Vehicle license numbers, passcode PINs, and gate clearance OTPs utilize tabular number spacing within Inter (`font-feature-settings: 'tnum' 1`) to eliminate character jitter during verification scans.

## Layout & Spacing
The layout relies on a strict 8pt spatial baseline to standardize components across resident mobile views, management desktop screens, and kiosk tablet interfaces.

- **Desktop (1024px+)**: 12-column responsive fluid grid bounded by a max container width of 1440px. Column gutters maintain `1.5rem` (`24px`) with safe outer canvas margins of `2rem` (`32px`). Multi-pane desktop layouts partition space into a fixed 260px administrative navigation drawer, a dynamic list panel (380px), and an active operational canvas.
- **Tablet (768px – 1023px)**: 8-column grid with `1rem` (`16px`) gutters and `1.5rem` (`24px`) margins. Sidebar transforms into a collapsible rail or modal drawer.
- **Mobile (< 768px)**: 4-column fluid layout with `0.75rem` (`12px`) gutters and `1rem` (`16px`) margins. Bottom sheet modals, fixed single-tap bottom action bars, and thumb-friendly vertical cards replace side-by-side data columns.

## Elevation & Depth
Visual hierarchy relies on crisp, controlled layering rather than aggressive shadow drops, preventing visual fatigue in data-dense resident management dashboards:

- **Level 0 (Flat / Canvas)**: Base background (`#F8FAFC`). Flat elements sit flush with a subtle border (`1px solid #E2E8F0`).
- **Level 1 (Card / Container)**: Primary content surfaces (`#FFFFFF`) with `1px solid #E2E8F0` and an ultra-diffuse ambient shadow: `0 1px 3px 0 rgba(15, 23, 42, 0.05), 0 1px 2px -1px rgba(15, 23, 42, 0.05)`.
- **Level 2 (Interactive Hover / Floating Panels)**: Raised cards on hover, quick filters, and dropdown menus: `0 4px 6px -1px rgba(15, 23, 42, 0.07), 0 2px 4px -2px rgba(15, 23, 42, 0.05)`, with border tinted to `#CBD5E1`.
- **Level 3 (Modals / Gate Alerts / Slide-outs)**: Critical clearance overlays, resident verification drawers, and emergency alerts: `0 20px 25px -5px rgba(15, 23, 42, 0.12), 0 8px 10px -6px rgba(15, 23, 42, 0.08)`.
- **Backdrop Dimming**: Critical security prompts and image viewfinders apply a deep navy veil (`rgba(15, 23, 42, 0.6)`) with `backdrop-filter: blur(4px)`.

## Shapes
The system establishes a clean, enterprise-ready curvature rhythm:

- **Base Radius (`0.5rem` / `8px`)**: Applied consistently to standard buttons, input fields, dropdown trigger targets, notification banners, standard cards, and modal dialogue containers.
- **Large Radius (`rounded-lg` / `1rem` / `16px`)**: Assigned to high-level parent overview containers, mobile bottom sheets, and promotional community event surfaces.
- **Extra Large Radius (`rounded-xl` / `1.5rem` / `24px`)**: Reserved exclusively for top-sheet dialogs and floating quick-action security triggers.
- **Pill Formats (`9999px`)**: Constrained strictly to status badges, micro chips, filter tokens, and resident unit tags (e.g., `A-402`).

## Components

### Buttons
- **Primary**: Solid Royal Blue (`#2563EB`) fill, `#FFFFFF` text, 8px radius, height: 44px (mobile: 48px touch target). Hover: `#1D4ED8`. Active: `#1E40AF`.
- **Secondary**: Slate-100 fill (`#F1F5F9`), Navy text (`#0F172A`), hover: `#E2E8F0`.
- **Outline / Ghost**: 1px border (`#E2E8F0`), transparent background, slate text (`#475569`), hover: `#F8FAFC`.
- **Emergency / SOS**: Crimson solid fill (`#EF4444`), white bold text, pulsing focus state ring (`rgba(239, 68, 68, 0.3)`).

### Chips & Status Badges
- Pill-shaped (`rounded-full`), height: 24px, uppercase `label-sm` tracking.
- **Approved / Paid / Resolved**: Emerald tint (`#ECFDF5`), border (`#A7F3D0`), text (`#065F46`).
- **Pending / In Review**: Amber tint (`#FFFBEB`), border (`#FDE68A`), text (`#92400E`).
- **Emergency / Overdue / Blocked**: Crimson tint (`#FEF2F2`), border (`#FECACA`), text (`#991B1B`).
- **Unit / Role Identifier**: Slate tint (`#F1F5F9`), border (`#CBD5E1`), text (`#334155`).

### Form Inputs & Selectors
- **Input Fields**: 44px height, `#FFFFFF` surface, 8px radius, border `1px solid #CBD5E1`. Placeholder: `#94A3B8`. 
- **Focus State**: `1px solid #2563EB` with an ambient glow (`box-shadow: 0 0 0 3px rgba(37, 99, 235, 0.15)`).
- **Error State**: `1px solid #EF4444` with error icon and red caption helper text.

### Selection Controls (Checkboxes & Radios)
- 20px box dimensions with 4px inner rounding (checkbox) or circle (radio). Active state fills with `#2563EB` and white inner glyph. Minimum 44x44px accessible touch container.

### Lists & Activity Feeds
- Borderless rows separated by `1px solid #F1F5F9` hairpins. Left-aligned unit avatar or icon badge, center stacked resident info (`title-md` + `body-sm`), and right-aligned timestamp and status chip badge. Hover triggers subtle background highlight (`#F8FAFC`).

### Gate Pass & Verification Cards
- High-contrast visual structure: `#FFFFFF` card body, top 4px color-coded semantic bar (Green for Approved, Red for Denied, Amber for Awaiting Action). Prominent tabular visitor code, QR code placeholder box with `#F8FAFC` containment, and dual full-width quick-action buttons ("Approve", "Deny").
